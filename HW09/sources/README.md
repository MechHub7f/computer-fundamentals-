# Source documents and register

Initial sources are listed in `manifest.json`; `download-log.json` records downloaded files and hashes. The originals are held locally in `originals/`, which is ignored by Git to avoid redistributing complete works. Run `python3 ../download_sources.py` from this directory to retrieve them. Passage verification against the scans remains incomplete.

Store original source documents here using descriptive filenames. Record the original URL, full citation, date, language, and source type for each document. Put extracted text and analytical notes in `../notes/`, keeping original documents unchanged.

Prefer stable archive, library, publisher, or DOI links in the paper's bibliography. If a source is available only through an online viewer, record the item URL and exact page/image identifiers and download it only when permitted.

## Coverage checks

- At least 10 sources in the final bibliography.
- At least half of them period primary sources.
- At least two written in a non-English language; a modern English translation alone does not establish that you consulted a non-English source.
- Financial evidence covering January 1725 purchase terms and sale opportunities in 1745–1750.
- Dividend evidence and consistent share/currency units.
- Evidence for the ethical comparison of both companies.

A modern scholarly article remains a secondary source even if it quotes historical documents. Link and cite the original document separately when you consult it directly.
